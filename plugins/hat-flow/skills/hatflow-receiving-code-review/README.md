# hatflow-receiving-code-review

接收代码审查反馈的处理规范。在实施审查建议前使用，确保技术严谨性和独立验证，避免盲目同意或不加思考地实现。

## 触发词

- "收到 review 反馈"
- "处理 review 意见"

## 核心原则

- 技术严谨：验证反馈的技术正确性
- 独立思考：不因审查者权威而跳过验证
- 质疑模糊建议：不清楚的反馈要追问

## 收编背景

2026-05-24 采纳自 obra/superpowers 的 5 个原子技能之一，2026-06-21 随 ISSUE 范式转变完成陈述式中文化。与全局 CLAUDE.md 的反奉承准则存在分层重叠：CLAUDE.md 定通用态度，本技能补充其独有增量——「反馈不清楚时全阻断」「实施顺序（阻断性问题优先）」「外部反馈五问核查」。经 hat-task-package 以 `hatflow-receiving-code-review` 名义打包进 hat-flow 公开分发。
